# nemesis-releases

Signed APKs and the short-video ruleset for **Nemesis Lock** and **Neuro Launcher**.

- **Install:** download both APKs from [Releases](../../releases) (same signing key, install both), or add this repository to Obtainium. Check the download against `SHA256SUMS`.
- **`rules.json`:** the ruleset Nemesis Lock downloads once a day (anonymous GET, no identifiers). The same rules are bundled in each APK.

This repository holds only release artifacts and the ruleset. The source code is not published here.
